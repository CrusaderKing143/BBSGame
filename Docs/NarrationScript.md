# 旁白脚本 Narration Script

主角是营销号写手，普通打工人。旁白是他的内心独白。全流程覆盖：开机 → 主界面 → 邮件 → 论坛 → 读帖 → 收集 → P图 → 发帖 → 下一轮 → 结局。

文风：日式轻小说。感官细节 + 自嘲式内心吐槽 + 画面感强的场景描写。

## 语气规则

- 第一人称现在时。先给一个能看见的画面，再接一句吐槽。
- 一框两到三句，英文 30 词以内。念出来要像人在自言自语，不是在朗读散文。
- 感官优先：光、味道、声音、手感、温度。别写"我很累"，写"椅子的皮革在我后背上黏了一层汗"。
- 吐槽要自嘲，不要炫。他是个loser，但他知道自己是loser，这就是笑点。
- 不抒情不总结。主题靠说漏嘴，不靠他讲道理。
- 中文别翻整齐。留「行吧」「得了」「这活儿」这种口气。

## 编号

`R1-X-02` = 第一关 / P图前 / 第 2 框。
段落：`B` 开机、`H` 主界面、`M` 邮件、`L` 点了没解锁的东西、`F` 首次进论坛、`P` 读帖、`C` 收集、`X` P图前、`D` P图中、`A` 提交后、`T` 过关、`E` 结局。

## 写更多时的注意

- **画面先行**：每框先给一个能看见/闻到/摸到的东西，再接吐槽。「凌晨四点手冰凉地坐在这儿」比「我很累」有用。
- **吐槽要自嘲**。他是个 loser，但他自己知道，这就是笑点。别让他显得聪明或酷。
- 他**从不**说「真相不重要」。他说流量、房租、脖子疼、他妈不问他工作了。主题从他在意什么、不在意什么里漏出来。
- `R2-X-04/05` 他真的在意 REN 清不清白 —— 这是第二关早退结局的地基。没这两框，粉丝结局显得没来由。
- 结局 3 那句「他们在吵那张图是不是真的」是全剧唯一一次直说主题。别加第二次。
- 复现道具串起全流程：**同一个酒保**（R1-X-03 / E-REPLAY-01）、**歪的扫描页和那个大拇指**（R2-M-02 / R3-A-PAP-01）、**凉茶**（H-REPEAT-03 / R2-P-04）。这些回声比台词有效，加新文本时尽量续上。
- `H-REPEAT` / `C` / `D` / `L` 是复用池，随机抽或按次数轮播，别每次同一句。
- 一框超过三句就拆。念出来像散文朗诵就重写成人话。
